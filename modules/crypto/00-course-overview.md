# Cryptography: CryptoBook Core Track

> A ByteSec course covering fundamentals, number theory, asymmetric cryptography, and symmetric cryptography.

---

## Course Scope

This course intentionally includes only these CryptoBook areas:

- Fundamentals
- Number Theory
- Asymmetric Cryptography
- Symmetric Cryptography

It does not include hashes, lattices, isogenies, appendices, or broader abstract algebra sections.

---

## Course Structure

| Module | Title | Duration | Difficulty |
|--------|-------|----------|------------|
| 01 | Crypto Fundamentals | 20 min | Beginner |
| 02 | Number Theory for Cryptography | 25 min | Intermediate |
| 03 | Asymmetric Cryptography | 30 min | Intermediate |
| 04 | Symmetric Cryptography | 25 min | Intermediate |

---

## Learning Model

The course focuses on the reasoning skills needed for CTF cryptography:

- Translate notation into concrete operations
- Compute modular arithmetic by hand
- Recognize where hard math problems create security
- Identify the constraints that make symmetric schemes safe or unsafe
