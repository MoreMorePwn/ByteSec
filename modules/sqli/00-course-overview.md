# 🛡️ SQL Injection: From Query to Conquest

> A Brilliant-style interactive course on understanding, exploiting, and defending against SQL Injection attacks.

---

## Course Philosophy

Like Brilliant.org, this course uses **learning by doing**. Every concept is immediately followed by an interactive challenge. Students never passively read — they **predict, experiment, and build** their understanding through hands-on problem-solving.

## Interactive Element Types Used

Throughout this course, we use the following Brilliant-style interaction patterns:

### 🧩 Multiple Choice (MC)
Classic question with 3-4 options. One correct answer. Used for concept checks.

### 🔤 Fill-in-the-Blank (FITB)
Student types in the missing SQL fragment. Tests precise syntax understanding.

### 🖱️ Drag & Drop (DND)
Rearrange SQL fragments or match items. Tests structural understanding.

### 💻 Live SQL Sandbox (SANDBOX)
Student writes and runs real SQL in a simulated environment. Sees immediate results.

### 🔍 Spot the Vulnerability (SPOT)
Given a code snippet, student highlights or selects the vulnerable line(s).

### 🧪 Predict the Output (PREDICT)
Student predicts what a query will return before it runs. Builds mental models.

### 🏗️ Build the Query (BUILD)
Construct a SQL injection payload step-by-step from given fragments.

### 🛡️ Fix the Code (FIX)
Given vulnerable code, student rewrites it to be secure.
